# Content Forge — Gen-AI Platform for Automated Content Transformation

**Smart India Hackathon 2025 • Problem Statement 26154 • NTRO • Theme: Smart Automation**

Content Forge transforms operator-submitted source content — raw text, documents (PDF/DOCX/TXT/MD), images, video metadata, URLs, and free-form prompts — into **7 operator-selected output formats** in one run. The operator controls **audience, tone, language, detail, objective, and style** for every transformation.

> **Stack:** Next.js 16.3 (App Router) • React 19 • TypeScript 5 (strict) • Tailwind 4 • Postgres (`pg` + `scripts/migrate.mjs`) • Gemini (`@google/genai`) / OpenAI • Zod • Vitest
> **No Python required.** Presenton has been removed — presentations are now generated by **Gemini**. Live AI is optional; deterministic fallbacks work without any API key.

## What Works

- **Ingestion** (`src/lib/ingest/`): text + PDF/DOCX/TXT/MD (≤10 MB per file), images (PNG/JPEG/WEBP), video metadata (MP4/WEBM), URL fetch with SSRF guard + 8 s timeout + no headless browser / no CAPTCHA bypass.
- **URL handling** (`src/lib/ingest/url.ts`): server-side fetch, strips scripts/styles, extracts text + embedded `<img>` sources.
- **Operator controls** (`src/lib/types.ts` → `TransformControls`): `audience` (free text), `tone` (Analytical/Conversational/Formal/Persuasive/Advisory/Playful), `language` (English/Hindi/Hinglish), `detail` (Brief/Standard/Detailed), `objective` (Inform/Persuade/Alert/Mobilize/…), `style` (Professional/Journalistic/Technical/Narrative/Bullet-brief), `outputs` (1–7 selected, `≥1` required).
- **Transformation engine** (`src/lib/transform/`): `transformSource(bundle, controls)` → `Promise.allSettled` across selected generators; partial success returned with warnings.
- **7 output generators** (`src/lib/outputs/`): `video`, `linkedin`, `twitter`, `advisory`, `infographic`, `summary`, `presentation` — each exports `generateX(bundle, controls) → Artefact` and degrades to a deterministic template when AI keys are missing.
- **Video** (`video.ts`): script + storyboard (6–8 scenes) + narration text + SRT/VTT + visual recs; ElevenLabs TTS when `ELEVENLABS_API_KEY` set, otherwise text-only with warning.
- **Presentation** (`presentation.ts`): **Gemini** generates 8–12 slides as structured JSON (`title` + 3–5 bullets + `notes` per slide) via `responseJsonSchema`; rendered as Markdown deck + speaker notes. Set `GEMINI_API_KEY` for AI decks, otherwise deterministic fallback.
- **Multi-output orchestration** via `POST /api/transform` (see API below) + browser-fallback persistence (`localStorage`) when Postgres is not configured.
- **Dashboard** (`src/components/transform-dashboard.tsx`): Source Intake → Controls Panel → Output Selector (7 checkboxes) → Generate → Artefacts Preview (tabs, copy/download). Legacy Orbita CRM is still available behind the same shell.

**Recent change:** Presenton (`PRESENTON_API_URL` / `PRESENTON_API_KEY`) has been **removed**. All presentation generation now uses the same `GEMINI_API_KEY`/`GEMINI_MODEL` as the rest of the platform. If you still have Presenton env vars, they are ignored.

## Output Types

| Output | Module | What you get |
|---|---|---|
| **Video Package** | `src/lib/outputs/video.ts` | 30/60/90 s script + storyboard + narration + SRT + visual/B-roll prompts; mp3 via ElevenLabs when configured |
| **LinkedIn Post** | `linkedin.ts` | 280–600 word professional post: hook + body + CTA + hashtags, tone-aware |
| **Twitter/X Post** | `twitter.ts` | 280-char tweet or 4–8 tweet thread with numbering + alt-text hints |
| **Advisory** | `advisory.ts` | Title / Classification / Summary / Background / Assessment / Recommendations / Distribution (Markdown, PDF-ready) |
| **Infographic** | `infographic.ts` | Headline + 5–7 data points + visual hierarchy / icons / color cues + copy blocks + CTA (content + layout spec, not a raster image) |
| **Executive Summary** | `summary.ts` | TL;DR + Context + Key Findings + Implications + Next Steps; length tied to `detail` (Brief 120w / Standard 300w / Detailed 600w) |
| **Presentation** | `presentation.ts` | 8–12 slides (Gemini JSON) + speaker notes per slide; Markdown deck. No Presenton required |

Common shape (`src/lib/types.ts`):

```ts
type Artefact = { type: OutputType; title: string; body: string; metadata: Record<string, unknown>; warnings: string[]; confidence: number };
type TransformResult = { sourceSummary: string; artefacts: Artefact[] };
```

## Architecture & Project Structure

```
src/app/                          Next.js App Router
  api/transform/route.ts          POST /api/transform  (primary SIH endpoint, Zod, multipart-ready)
  api/jobs/route.ts               GET  /api/jobs        (history, DB or browser)
  api/jobs/[id]/route.ts          GET  /api/jobs/:id
  api/assistant/route.ts          POST /api/assistant   (plan + refine {jobId, artefactType, instruction})
  api/health/route.ts             GET  /api/health      (integrations: database, ai, elevenlabs, presentation, ingestion)
  api/content/route.ts            POST /api/content     (legacy single-platform draft, deprecated)
  api/state/route.ts              GET/PUT /api/state    (browser ↔ Postgres sync)
  layout.tsx  page.tsx

src/components/
  orbita-app.tsx                  Shell + nav (Transform is the default tab)
  transform-dashboard.tsx         Main operator console
  ingest-dropzone.tsx             Text + URL + file picker, parsed preview
  controls-panel.tsx              6 controls (audience/tone/language/detail/objective/style)
  output-selector.tsx             7 checkboxes, ≥1 required
  artefact-preview.tsx            Tabbed preview + copy/download, warnings + confidence

src/lib/
  types.ts                        Platform, TransformControls, SourceBundle, Artefact, …
  orbita-engine.ts                Deterministic fallback helpers (draftBody, etc.)
  ai.ts                           provider() → gemini | openai | demo, JSON-schema helpers
  ingest/  parse.ts  url.ts  image.ts  video.ts  normalize.ts
  transform/  index.ts (orchestrator)  prompt.ts (instruction builder)
  outputs/  video.ts  linkedin.ts  twitter.ts  advisory.ts  infographic.ts  summary.ts  presentation.ts (Gemini)
  db.ts                           pg pool + ensureCoreSchema() + hasDatabase()

db/migrations/
  001_initial_schema.sql          21 tables (users, campaigns, content_items, memories, audit_logs, …)
  002_content_forge.sql           transformation_jobs, artefacts, source_documents

scripts/migrate.mjs               Sorted .sql runner + schema_migrations table
.env.example                      Template (copy to .env.local)
```

Pipeline: `Ingest → Normalize → Transform (controls → prompts) → 7 Generators (Gemini/OpenAI or fallback) → Artefacts`

## Full Setup — Step by Step

### 1. Clone and install

```bash
git clone <repo-url>
cd Gen-AI-Platform-for-Automated-Content-Transformation
npm install
```

If `npm install` fails, delete `node_modules` and `package-lock.json` and retry, or run `npm ci`.

### 2. Configure environment

```bash
# PowerShell
Copy-Item .env.example .env.local

# bash / macOS / Linux
cp .env.example .env.local
```

Open `.env.local` and set:

```ini
# No access code required — app opens directly

# At least one for live AI (Presentation also uses GEMINI_API_KEY)
GEMINI_API_KEY=your-gemini-key
GEMINI_MODEL=gemini-3.6-flash
# or
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-5-mini

# Optional — Postgres (leave empty for browser demo mode)
DATABASE_URL=postgresql://user:pass@localhost:5432/content_forge

# Optional — Video narration
ELEVENLABS_API_KEY=...
ELEVENLABS_VOICE_ID=21m00Tcm4TlvDq8ikWAM
```

> **Never commit `.env.local`.** It is gitignored. Use `.env.example` as the committed template.

### 3. Database (optional)

```bash
# Requires DATABASE_URL in .env.local
npm run db:migrate
# Applies db/migrations/*.sql in order via scripts/migrate.mjs
```

- If `DATABASE_URL` is missing, `/api/health` reports `database: false` and `demoMode: true` — the app still works.
- To run Postgres locally: `createdb content_forge` (or via Docker) then set `DATABASE_URL`.

### 4. Run the dev server

```bash
npm run dev
# → http://localhost:3000
```

- No login — the app opens directly to the **Transform** dashboard.
- Use **Transform**: paste text or a URL → set controls → check 1–7 outputs → **Generate** → preview tabs.
- Health check: `http://localhost:3000/api/health` shows `integrations: { database, ai, aiProvider, elevenlabs, presentation, ingestion }` — note `presentation` is `true` when `GEMINI_API_KEY` is set.

### 5. Try the API directly

```bash

  -H "Content-Type: application/json" \
  -d '{

      "audience": "NTRO analysts",

      "style": "Professional",
      "outputs": ["LinkedIn", "ExecutiveSummary", "Presentation"]

# With a URL as source
```

## API Reference

| Route | Method | Body / Notes |
|---|---|---|
| `/api/transform` | **POST** | `{ text?, prompt?, url?, docs?: {filename,mime,text}[], controls: TransformControls }` → `{ jobId, sourceSummary, artefacts: Artefact[], status: "done" | "partial" }`. Zod-validated. Multi-output via `Promise.allSettled`. Rate-limit suggestion: 10 jobs/hour/IP. |
| `/api/jobs` | **GET** | List jobs (DB when `DATABASE_URL` set, else `[]` + note) |
| `/api/jobs/:id` | **GET** | Fetch one job by id |
| `/api/assistant` | **POST** | Either `{ command: string (3–1200) }` → command plan, or refine mode `{ jobId, artefactType, instruction }` → revised artefact |
| `/api/health` | **GET** | `{ status, demoMode, integrations: { database, ai, aiProvider, elevenlabs, presentation, ingestion } }` — `presentation` reflects `GEMINI_API_KEY` |
| `/api/content` | **POST** | Legacy single-platform draft (`platform/topic/audience/objective`) — deprecated, kept as alias |
| `/api/state` | **GET / PUT** | `browser ↔ Postgres` sync for `PersistedState` |

```bash
curl -X POST http://localhost:3000/api/transform \
```

## Troubleshooting

| Symptom | Fix |
|---|---|
| `python -m venv` / `pip install -r requirements.txt` fails | **Expected** — this is a Next.js project, not Python. Use `npm install` → `npm run dev`. |
| `GEMINI_API_KEY not set` warning in Presentation artefact | Set `GEMINI_API_KEY` in `.env.local` and restart `npm run dev`. Deterministic fallback is normal without it. |
| `database: false` in `/api/health` | Set `DATABASE_URL` and run `npm run db:migrate`, or keep using browser demo mode (no action needed). |
| `ELEVENLABS_API_KEY` warning in Video | Video still returns script+storyboard+SRT; audio needs the key. |
| Port 3000 in use | `PORT=3001 npm run dev` or kill the other process. |
| `npm run build` fails with `.next/dev/types` errors | `Remove-Item -Recurse -Force .next` (PowerShell) or `rm -rf .next` (bash) then rebuild. |

## Security Notes

- Never commit `.env.local` (gitignored).
- Zod validates every API boundary; file MIME + size checks; URL SSRF guard blocks private IPs (`src/lib/ingest/url.ts`).
- URL fetch is a simple `GET` with `User-Agent: ContentForge/1.0`, 8 s timeout, no headless browser, no CAPTCHA bypass — see `SECURITY.md`.
- `GET /api/health` returns booleans, never secret values.

## Known Limitations

- Presentation uses **Gemini** (`GEMINI_API_KEY`) — no Presenton, no self-host needed; without the key you get a deterministic 8-slide fallback deck.
- Video narration needs `ELEVENLABS_API_KEY` (otherwise script/storyboard/SRT only).
- Live AI needs `GEMINI_API_KEY` or `OPENAI_API_KEY` (otherwise deterministic templates per generator).
