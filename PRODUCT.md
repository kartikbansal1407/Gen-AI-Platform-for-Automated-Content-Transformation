# Product

Orbita helps one person deliberately build an online presence through ideas, content, distribution, relevant people, conversations, relationships, and opportunities.

## Core Principles

- Conversational first.
- The user stays in control of genuine interactions.
- Prefer useful relationships over vanity metrics.
- Avoid spam, fake engagement, and platform abuse.
- Make memory inspectable and editable.
- Provide manual/assisted workflows when integrations are unavailable.

## Main Sections

- Home
- Create
- Campaigns
- Discover
- Network
- Analytics
- Memory
- Settings

## Voice Defaults

Analytical, conversational, young but intelligent, curious, occasionally contrarian, natural, and not unnecessarily formal.

Avoid generic AI writing, corporate jargon, excessive emojis, fake vulnerability, and generic LinkedIn guru phrasing.
